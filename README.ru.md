# ACVPN для Windows

[English](README.md) | **Русский**

ACVPN — приложение для подключения к вашим серверам и подпискам через локальный прокси на Windows. Версия на Tauri использует Windows WebView2 для интерфейса, встроенный Node.js для логики приложения и sing-box для соединения. Приложение не предоставляет серверы или подписки: их необходимо получить у провайдера или настроить самостоятельно.

## Возможности

- Импорт отдельных конфигураций и HTTPS-подписок, обновление подписок.
- Поиск и сортировка серверов, список избранного, проверка задержки и сертификатов.
- Системный прокси Windows или ручная настройка локального HTTP/SOCKS5-прокси.
- Правила для сайтов и приложений: напрямую, через прокси или блокировать.
- Русский и английский языки, светлая и тёмная темы, работа в системном трее.

## Установка и подключение

1. Скачайте `ACVPN-Tauri-Setup-2.0.5.exe` из [релизов GitHub](https://github.com/kameker/ACVPN/releases/latest) и запустите его. Установщик не подписан, поэтому Windows может показать предупреждение о неизвестном издателе.
2. Нажмите «Добавить» и вставьте ссылку конфигурации или HTTPS-ссылку подписки.
3. Выберите сервер и нажмите кнопку подключения.
4. Для отключения нажмите кнопку ещё раз. Закрытие окна сворачивает приложение в трей; для полного выхода используйте меню значка в трее.

Установщик проверяет наличие Microsoft Edge WebView2 Runtime и при необходимости скачивает его; для этого требуется интернет. Node.js, sing-box и необходимая библиотека sing-box включены в ACVPN и не требуют отдельной установки.

По умолчанию ACVPN настраивает системный прокси Windows. Через него работают приложения, использующие системные настройки; программы, которые их игнорируют, автоматически перенаправлены не будут. В настройках можно отключить системный режим и вручную указать в нужной программе HTTP- или SOCKS5-прокси `127.0.0.1:2080`.

При обычном отключении ACVPN восстанавливает прежние настройки прокси, если они не были изменены другой программой. В системном режиме приложение запускает помощник восстановления и создаёт отдельную запись для запуска при входе в Windows, даже если автозапуск самого приложения выключен. Помощник пытается восстановить настройки после аварийного завершения backend и при следующем входе пользователя. Если настройки изменились извне, ACVPN сохраняет запись и предлагает оставить текущие настройки либо восстановить сохранённые.

При переходе с версии на Electron отключитесь и полностью закройте старое приложение через меню в трее, затем установите 2.0.5 вручную. Новая версия импортирует зашифрованный профиль в отдельный каталог, не изменяя старые файлы; старая установка автоматически не удаляется. Если ключ шифрования старого профиля отсутствует, ACVPN предложит создать пустой профиль. Старые файлы сохранятся, но подписки потребуется добавить заново, если исходный ключ не удастся восстановить.

## Серверы и подписки

«Чек пинг» измеряет время прямого TCP-соединения с сервером и запускает проверку обычного TLS-сертификата через сервер с подключением к `www.cloudflare.com:443`. Проверка раскрывает факт подключения VPN-серверу и Cloudflare. Сетевые ошибки и ошибки сертификата показываются отдельно; для Reality, соединений без TLS и с отключённой проверкой предусмотрены отдельные статусы. Проверенный сертификат не гарантирует работоспособность сервера, а задержка не измеряет скорость соединения.

По умолчанию серверы и избранное сортируются по пингу: сначала идут серверы с измеренной задержкой и проверенным сертификатом, затем подходящие серверы без обычного TLS-сертификата; остальные остаются видны ниже. Страна определяется по названию сервера, а не по его IP. При выборе другого сервера во время подключения приложение переключается на него.

Кнопка «Обновить» обновляет подписки; перед обновлением необходимо отключиться и дождаться окончания проверки серверов. Управление отдельными подписками доступно в режиме сортировки «По подпискам».

Некоторые провайдеры требуют идентификатор устройства. При добавлении подписки можно разрешить его передачу: для этой ссылки ACVPN отправляет постоянный случайный `X-HWID`, название и версию ОС и имя пользователя в формате `ОС-пользователь`. Провайдер может засчитать его как отдельное устройство, а отображение имени зависит от провайдера. Идентификатор и разрешения хранятся локально в зашифрованном виде. Если провайдер вернул только заглушку «App not supported», сохранённые серверы ею не заменяются.

## Маршрутизация и ограничения

- Поддерживаются URI VLESS, VMess (base64 JSON), Trojan, Shadowsocks (SIP002) и SOCKS5; подписки могут содержать список URI в обычном виде или base64. Неподдерживаемые строки пропускаются; импорт отклоняется, если поддерживаемых строк нет.
- Для соответствующих ссылок поддерживаются VLESS Reality и TLS, TCP, WebSocket и gRPC. Не все параметры провайдеров поддерживаются; Hysteria2, Shadowsocks-плагины, прямой импорт JSON, файлов и QR-кодов не реализованы.
- Правила сайтов применяются только к трафику, поступившему в локальный прокси; доменные правила включают поддомены. Правила приложений сопоставляют полный путь `.exe` и проверяются раньше правил сайтов. Приложение можно выбрать среди запущенных процессов или указать путь вручную. Изменения правил вступают в силу после переподключения.
- **Готовые исключения** позволяют загрузить российские категории из [geosite.dat и geoip.dat Loyalsoldier](https://github.com/Loyalsoldier/v2ray-rules-dat). Кнопка «Всё про РФ» включает или выключает все категории, загружая недостающие базы. Она сохраняет выбранные действия, а для новых категорий выбирает прямое подключение. В детальных настройках можно обновить базы, включить отдельные категории и выбрать действие: напрямую, через VPN или блокировать. GeoIP сопоставляет IP-адрес, переданный в прокси; домен специально для этого правила автоматически не разрешается. Сначала проверяются правила приложений, затем ручные правила сайтов, затем включённые списки в указанном порядке. Обновление запускается вручную; при ошибке сохраняется последняя рабочая версия. Чтобы применить изменения, переподключитесь.
- Системный прокси не обеспечивает перенаправление всего трафика: UDP и DNS могут идти напрямую. Kill switch, защита от утечек, собственная настройка DNS, проверка внешнего IP и автоматическое восстановление после потери сети не реализованы.
- Существующие исключения Windows и автоматическое обнаружение прокси могут влиять на маршрутизацию. Если в Windows задан PAC URL, включение системного режима отклоняется.
- Статус «Прокси запущен» означает, что запущен sing-box и отвечает локальный порт. Он не подтверждает аутентификацию, доступность удалённого сервера или отсутствие утечек. Локальный прокси без аутентификации доступен другим процессам на этом компьютере.
- При переключении серверов соединение прерывается, и без kill switch возможен прямой доступ. Восстановление после сбоя или потери питания не гарантировано: необходимы пользовательский сеанс Windows, доступ к зашифрованной записи и исправные настройки прокси Windows. Процесс ядра в отдельных случаях может потребовать ручного завершения. Другая программа может изменить настройки между их проверкой и восстановлением.

## Данные и обновления

Настройки, конфигурации и ссылки подписок хранятся в зашифрованном файле `data.enc` в каталоге `%APPDATA%\app.acvpn.tauri`. Формат совместим с Electron `safeStorage`, а ключ шифрования защищён Windows DPAPI. Конфигурация передаётся sing-box через стандартный ввод; во время работы данные доступны процессам той же учётной записи. Аналитика отсутствует.

HTTPS-подписки загружаются по указанному адресу без перенаправлений; размер ответа ограничен 2 МБ. Обновления приложения устанавливаются вручную: скачайте новый установщик из релизов GitHub, отключитесь и полностью закройте ACVPN, затем запустите установщик. Установщик не подписан.

## Разработка и сборка

Для сборки версии Tauri нужны Windows, Node.js 24.13.1, npm, Rust, средства Microsoft C++ и WebView2. В CI используется Rust 1.99.1:

```powershell
npm ci
npm test
cargo test --locked --manifest-path src-tauri/Cargo.toml
npm run tauri:build -- --ci --no-sign
```

Установщик создаётся в `src-tauri/target/release/bundle/nsis/`, если не задан `CARGO_TARGET_DIR`. Для запуска приложения при разработке используйте `npm start`. Тесты проверяют обработку и перенос данных, конфигурации sing-box, маршрутизацию и TLS с локальными тестовыми серверами. Пользовательский сервер или подписка в тесты не входят.

[GitHub Actions](https://github.com/kameker/ACVPN/actions/workflows/windows-build.yml) устанавливает зависимости, запускает тесты и собирает установщик Windows при изменениях в `main`, для pull request и по ручному запуску. Установщик сохраняется на 14 дней как `ACVPN-Tauri-Windows-unsigned`. Этот процесс не подписывает установщик и не публикует релиз. Установщики релизов имеют имя `ACVPN-Setup-<версия>.exe`.

### Цифровая подпись Windows

Для доверенной подписи необходим действующий сертификат Code Signing с доступным закрытым ключом. Подписание установщика Tauri требует отдельной настройки по инструкции поставщика сертификата. Не добавляйте ключи и пароли в репозиторий.

После подписания проверьте установщик и основной `acvpn-tauri.exe` командой PowerShell `Get-AuthenticodeSignature`: статус должен быть `Valid`. Подпись не гарантирует немедленного исчезновения предупреждений SmartScreen. Подписание через SignPath требует отдельного одобрения и настройки.
