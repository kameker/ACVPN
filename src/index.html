Правила сайтов

Применяются только к трафику через локальный прокси. Первое совпадение побеждает; домены включают поддомены.

Изменения правил применяются при следующем подключении.

Приложения

Выберите .exe и действие для его трафика.

Правила приложений действуют только на трафик через ACVPN. Они проверяются раньше правил сайтов. DNS в TUN обрабатывается отдельно. Изменения вступают в силу после переподключения; TUN экспериментальный.

Параметры

Настройте ACVPN под себя.

Доступен только локальный HTTP/SOCKS5-прокси. Системный прокси и настройки Windows не изменяются. DNS использует настройки ядра по умолчанию; kill switch отсутствует.
